# CinemaAudienceQuizzer

CinemaAudienceQuizzer is a Blazor-based web application that allows cinema audiences to participate in a fun movie runtime guessing game. Each participant submits their guess for the runtime of a featured movie, and after the actual runtime is revealed, the leaderboard displays all guesses, highlighting the closest guess(es). If multiple participants are equally close, all are recognized as winners.

The game is intended to be played in an offline environment. If you want to publish it in the cloud, feel free.

## Features

- **Movie Poster Display:** Shows the current movie's poster to all participants.
- **Guess Submission:** Audience members enter their seat number and guess the movie's runtime in minutes.
- **Real-Time Updates:** Uses SignalR to update the UI in real time as guesses are submitted and the runtime is revealed.
- **Leaderboard:** Displays all guesses, their differences from the actual runtime, and highlights all closest guesses as winners.
- **Dark Theme:** The application uses a modern dark look for comfortable viewing in cinema environments.
- **No Navigation Bar:** The navigation bar is hidden for a distraction-free experience.

## How It Works

1. The quiz master sets up the movie and reveals the poster.
2. Audience members submit their seat number and runtime guess.
3. Once all guesses are in, the actual runtime is revealed.
4. The leaderboard displays all guesses, and the closest guess(es) are highlighted as winners.

# Installation
As I inteded this game for an offline environment, you need to be aware of the player size. Your Wifi needs to be able to accommodate the number of IP addresses, as well as the traffic of the game. That being said, I can give you the guidance to provision 230 players maximum. I haven't tried more with my technical setup:

## Technical Setup
It is taken as the given situation, that you do not have the Wifi infrastructure yet.
In case you have a potent Wifi infrastructure, you can directly head over to the laptop/pc installation.

### Components
1. TP-Link 660HD EAP for provisioning Wifi to all clients
2. Raspberry Pi 4 as DHCP Server
3. A Laptop / PC to host the game and stream the image on the screen (if you like. Streaming the image on the screen is optional)
4. A mobile phone, to control the game

### Software Setup
1. Install the EAP as instructed
2. Install DietPi on the Raspberry Pi
3. Install dnsmasq on the Raspberry Pi and setup the IP range
4. For the hosting laptop/pc: Install Visual Studio (Code), .NET Framework and set the laptop/pc in the same Wifi environment as your players
5. Have your mobile phone in the same Wifi as Laptop and players, too.

### Game Setup
1. Change the hash code for admin authentication page (generate your own hashcode for your own password and insert it)
2. Change the wifi.png qr code image with a qr code image of your own wifi to connect with.
3. Start the program in Visual Studio
4. For your initial opening of the page as the game master, open your commandline and look for your ipv4 address of your laptop. Type in "ipconfig" (windows) and copy the address to the browser, followed by port 5000 (eg 198.168.0.1:5000).
5. Go to the admin page (198.168.0.1:5000/admin) and login.
6. Admin page: Set the visible page to the wifi qr code. Let users connect to the wifi
7. Admin page: Set the visible page to the game page - an autogenerated qr code to connect with the hosting laptop appears per default. Let users connect to the page
8. Game is set to be played: Upload the image of a movie poster and set the runtime of the movie and press "set up game"
9. Wait until users put in their guess. Press "reveal" in the admin page for closing the round and revealing who was the closest
10. Repeat as you like
